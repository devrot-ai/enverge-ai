Features

World Generation

Generate deterministic buggy code environments from 14 templates covering Flask, Django, React, Spring, Express, Go, TypeScript, and more.

Agent Execution

Run 6 agent types including MockAgent, RuleBasedAgent, ScriptAgent, OpenAI, Claude, and Ollama-compatible agents.

Verification

Independent test execution with public and hidden tests, static analysis, fuzzing, and performance regression detection.

Adaptive Curriculum

Automatic difficulty scaling, multi-agent tracking, cross-domain knowledge transfer, and capability-based task selection.

Experiments

7 preset experiments with A/B testing, statistical analysis, custom YAML experiment definitions, and MLflow integration.

Training Data

Normalized trajectory export, reward computation, SFT/RL format, dataset versioning, and Hugging Face TRL integration.

Getting Started

Local Development

git clone https://github.com/devrot-ai/enverge-ai.git
cd enverge-ai
pip install -e .
forgelab doctor

Run Demo

python examples/demo_pipeline.py

Generates worlds, creates tasks, runs agents, verifies fixes, and updates curriculum.

Run Tests

python -m pytest tests/ -v

645 tests covering all modules including integration tests.
